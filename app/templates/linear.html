Regularisation — stopping the fit from memorising

  • Ridge (L2) — adds λ·Σw². Shrinks weights smoothly; never zeroes them.
  • Lasso (L1) — adds λ·Σ|w|. Drives weak weights to exactly 0 → built-in feature selection.
  • Elastic net — L1 + L2. Best of both when features are correlated (our semester grades are).
  • Geometry: the loss contour touches the L1 diamond at a corner — and a corner means a zero weight.
λ trade-off: λ = 0 → overfit; λ → ∞ → all weights zero. Choose λ with cross-validation.

Sigmoid & cross-entropy loss

Logistic regression — the deployed model

A linear decision boundary plus a sigmoid, trained by gradient descent on cross-entropy.

1 · Model P(y=1|x) = σ(w·x + b) The decision boundary w·x + b = 0 is a hyperplane; σ bends the output into (0,1).
2 · Loss −[y·log p + (1−y)·log(1−p)] Cross-entropy — the standard loss for probabilistic binary classification.
3 · Optimise w ← w − η·∇L(w) (+ ridge term) Log-loss is convex → gradient descent finds the global optimum.

Multinomial (softmax) regression — beyond two classes

For k classes the model outputs k weight vectors and applies softmax(z)ᵢ = e^zᵢ / Σⱼ e^zⱼ, giving a probability distribution that sums to 1. Binary logistic regression is exactly the k = 2 case. Our task is binary (Placed Not Placed), so plain logistic regression is the right tool.
