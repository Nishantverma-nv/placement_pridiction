Evaluation

Everything measured on the same untouched 20% hold-out set — no model ever sees it during training.

How to read the metrics

AccuracyShare of correct predictions. Misleading on imbalanced data — 66% by guessing “Placed”.
PrecisionOf those we called Placed, how many were right? — the cost of a false positive.
RecallOf all truly Placed students, how many did we catch? — the cost of a false negative.
F1Harmonic mean of precision and recall — the single number we optimise for deployment.
ROC-AUCProbability a random placed student ranks above a random non-placed one. 0.5 = chance.
Confusion matrixTP / FP / TN / FN — where exactly the errors land.
