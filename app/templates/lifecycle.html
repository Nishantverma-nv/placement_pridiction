Which kind of learning is this?

Supervised labels exist: Placed / Not Placed. PlacementPredict learns a mapping from profile → outcome.

Not unsupervised we are not discovering groups with no labels — though M4 clustering is used to explore the same data.

Not reinforcement learning there is no agent, no actions, no reward loop.

Tracing one prediction end to end

HTTP POST→ Feature lookup→ transform()→ predict_proba()→ JSON

Batch prediction is the same path — the form accepts many rows and scores them in one call. Try POST /api/predict.

The training–serving boundary. The bug that bites most production systems is training-serving skew — features prepared differently at serve time than at train time. Feature stores exist to keep one canonical definition. Here the fitted pipeline.pkl guarantees the exact same transform path from day one.
